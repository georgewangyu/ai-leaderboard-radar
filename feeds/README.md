# Feeds

Weekly public AI Leaderboard Radar feeds live here:

```text
feeds/YYYY/MM/YYYY-MM-DD.md
```

The feed is updated after the source sync. It highlights newly seen companies
first, then falls back to a rotation from the existing catalog when no new rows
are found.

Installed agents should treat the newest feed as the digest source of truth.
They should not invent company metrics during digest delivery.
